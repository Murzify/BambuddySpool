# MVP-008 — Guarded NFC Tag Linking Runtime

## Scope

Bind the existing shared Link/Overwrite/Clear workflow to the production root and Android NDEF bridge without
adding a Bambuddy mutation path.

## Delivered

- The Spool detail Link action enters a process-local live-tag state and arms only the Android foreground reader.
- Foreground reader mode is enabled only while a Link/Retry read is armed, then disabled on cancellation or before
  physical I/O; ordinary NFC intent routing remains available outside that workflow.
- Android keeps a framework `Tag` only in a short-lived adapter; common/root state receives a classified read and
  fingerprint only.
- Every link, including an empty tag, presents explicit confirmation before a physical write.
- Confirmation opens a short-lived policy-bound Ktor session and performs the existing authentication and selected
  spool GET validation immediately before calling the fingerprint-bound NDEF writer.
- The existing Android writer still enforces capacity/writability, rejects fingerprint changes, and independently
  rereads the canonical payload. No irreversible lock is exposed.
- Cancellation consumes the process-local tag. Recreating the root drops selected spool, tag state, and any
  authorization.
- An uncertain physical result must enter an explicit retry state, arm the reader again, and accept only the same
  fingerprint before it can return to a confirmation-capable state.

## Verification

`./gradlew :shared:testAndroidHostTest :androidApp:assembleDebug --rerun-tasks`

Result: passed. The Android host suite includes production-routing coverage showing that link starts a live read,
an unsupported replacement tag fails before a write, and transient tag state is not restored.

## Safety Notes

No private Bambuddy request, Bambuddy POST, NFC physical write, token logging, fixture capture, or tag locking was
performed for this task.

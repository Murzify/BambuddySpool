# [MVP]-[003] Preserve the Contract-Required Printer Collection Path

## Status: Implemented

## Root Cause

The Bambuddy 0.2.4.7 mandatory contract specifies the printer collection as
`GET /api/v1/printers/`. A slashless collection request is not equivalent on the target server: an
owner-authorized read-only contract check observed `404` for the slashless path and `200` for the documented path.

`KtorBambuddyRepository.getPrinters` preserves the terminal slash through its bounded URL builder, including when
the configured URL contains a base path. The behavior already existed in the repository boundary; this task makes
the contract dependency explicit and protects it with a focused regression test.

## Scope and Safety

- No live/private request was made during implementation or verification.
- No private URL, credential, response body, or inventory data was stored.
- Mutation endpoints, redirect handling, HTTP consent, and TLS policy were not changed.

## Verification

- `KtorBambuddyRepositoryTest.printerCollectionUsesTheContractRequiredTrailingSlash` uses `MockEngine` and returns
  success only for `/proxy/api/v1/printers/`; any slashless request receives synthetic `404`.

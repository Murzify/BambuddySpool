# [SEC]-[002] Enforce URL, Redirect, HTTP, and TLS Policies

## Status: Partially Implemented

The shared Ktor boundary now owns network-trust decisions. It starts fail-closed until persisted connection
settings construct `ConfiguredBambuddyNetworkSecurityPolicy`.

- Initial requests must use the exact configured origin and remain within its canonical optional base path.
- HTTP requests require an acknowledgement for that exact canonical HTTP origin.
- Redirects stay disabled in Ktor and are followed manually only after validation. The boundary allows same-origin
  targets or a same-host HTTP-to-HTTPS upgrade, rejects hostname/DNS-IP changes, downgrades, loops, malformed
  targets, and a sixth hop. A denied target receives no `X-API-Key` request.
- Android OkHttp and iOS Darwin retain normal platform certificate and hostname verification. No global trust-all
  manager, insecure hostname verifier, or redirect-inherited TLS exception exists. The TLS decision is restricted
  to the exact configured HTTPS hostname and is reversible when the stored hostname is cleared; until a
  platform-safe host-scoped retry adapter is wired, certificate failures remain fail-closed. That adapter is the
  explicit remaining `[SEC]-[005]` task; therefore `[SEC]-[002]` remains open.

## Evidence

- `ConfiguredBambuddyNetworkSecurityPolicyTest` covers HTTP-consent scope, base-path enforcement, upgrade-only
  redirects, host/DNS-IP and downgrade rejection, redirect limit, exact-host TLS decision, and reversibility.
- `KtorBambuddyRepositoryTest` proves a denied redirect produces a security error and only the original approved
  request observes the synthetic credential.
- `./gradlew :shared:allTests --no-daemon` passed on Android host and iOS simulator targets.

## Scope notes

This task deliberately preserves the MVP's fail-closed runtime: connection Test/Save cannot activate networking
until the composition root wires secure settings, credentials, and this policy together. No private instance was
accessed and no mutation endpoint was called.

# MVP-013 — Retain NFC Ownership Until Terminal Dismissal

## Scope

Prevent Android from rediscovering a just-written held NDEF tag through the application's canonical intent filter
after a physical tag mutation finishes.

## Delivered

- The Android-only foreground-reader lifecycle now has a terminal phase. It retains reader ownership and rejects
  callbacks after the writer and independent read-back finish, until the user dismisses the transient result.
- A terminal failed operation can move back to awaiting a physical retry without an extra reader-mode enable call.
- Activity pause force-releases live reader ownership. The bridge still prevents normal cancellation from replacing
  a tag while physical I/O is in progress.
- The successful link surface now asks the user to remove the tag and offers a dedicated Done action instead of
  presenting Cancel as completion.

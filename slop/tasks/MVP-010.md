# MVP-010 — Android NFC Permission Declaration

## Scope

Fix the foreground reader-mode crash caused by an absent Android NFC permission declaration, without changing the
optional NFC hardware feature or any NFC, network, or mutation workflow.

## Delivered

- Added `android.permission.NFC` to the application manifest. This is a normal Android permission and is required
  before `NfcAdapter.enableReaderMode` can be used.
- Retained `android.hardware.nfc` with `android:required="false"`, so devices without NFC remain eligible to
  install and use non-NFC functionality.
- Extended the existing Android manifest/device test to assert that the installed app receives NFC permission.

## Verification

The focused Android instrumentation class passed four tests. Built-artifact inspection confirmed the NFC
permission in the debug APK.

## Safety Notes

No private configuration was read. No Bambuddy request, POST, physical NFC write, tag lock, or secret logging
occurred.

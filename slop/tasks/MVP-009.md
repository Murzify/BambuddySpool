# MVP-009 Completion Report

## Summary

Home now projects the configured connection and the existing printer-cache availability together. A configured
instance is shown as online only after the MVP cache has published a non-stale, supported snapshot with
`MutationAvailability.Available`. This removes the false stale message after a successful initial A1 sync and
matches the existing guarded manual-assignment availability.

## Safety Boundary

- Initial synchronization remains GET-only.
- A cache that is initial-loading, refreshing, failed, stale, or degraded remains stale on Home.
- Unsupported topology remains mutation-disabled; Home does not infer action availability from configured settings.
- No private endpoint request, Bambuddy POST, credential logging, or NFC write was performed.

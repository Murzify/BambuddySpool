# [MVP]-[002] Wire a Constrained Read-Only Runtime

## Status: Implemented

The production connection bridge now constructs `KtorBambuddyRepository` instances only with the configured
network-security policy and an immediate Keystore-backed credential provider. Connection Test validates the HTTPS
endpoint and API key. Save validates first, replaces the token through the supplied secure store, performs one
complete GET-only snapshot synchronization, and rolls settings/token back if that synchronization fails.

The temporary cache projects only the validated full snapshot for Home, Spools, and Printers. It reports mutation
availability as disabled and binds neither assignment POST nor NFC tag-writing operations. HTTP remains denied at
the policy boundary until an explicit persisted-origin consent flow is available.

## Deliberate POC limitation

This repository has no usable platform Room or DataStore composition factory (and does not apply a Room compiler).
For this owner-approved POC, connection presentation state and the snapshot cache are process-local. They disappear
on process death and must not be represented as offline persistence. The token remains exclusively behind the
Android Keystore-backed `SecureTokenStore` and is never put in state, navigation, cache, or documentation.

## Evidence

- `./gradlew :androidApp:assembleDebug` compiles the Android production graph with the runtime binding.
- No live/private Bambuddy request was made, and no mutation endpoint was exercised.

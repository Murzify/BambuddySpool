# MVP-011 — Blank Formattable NFC Tag Linking

## Scope

Repair the Android foreground-link reader so a blank NDEF-formatable tag reaches the existing explicit link
confirmation and writer instead of being rejected before formatting.

## Delivered

- Tags exposing `Ndef` continue through normal content classification.
- Tags without `Ndef` but with `NdefFormatable` are classified as empty. They still require the existing user
  confirmation, fresh GET-only selected-spool validation, fingerprint continuity, physical write, and independent
  read-back before success.
- Tags with neither supported capability remain unsupported and cannot reach the writer.
- Foreground reader mode no longer requests `FLAG_READER_SKIP_NDEF_CHECK`, because the linking flow must inspect
  NDEF content.
- Every tag-mutation confirmation explicitly tells the user to keep the tag held through write and independent
  read-back verification.

## Safety Notes

No private configuration or Bambuddy endpoint was read. No Bambuddy POST, physical NFC write, tag overwrite,
clear, lock, secret logging, or fixture capture was performed.
